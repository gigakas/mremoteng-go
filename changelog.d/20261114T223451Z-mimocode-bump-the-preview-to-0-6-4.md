Bump the preview to 0.6.4

0.6.3 was packaged before the SFTP browser existed, so its tarball carries a single binary and none of the last two days of work: the two-pane file transfer window, the RD Gateway rewrite, per-profile RDP options with the exit report, restored session tabs with their split layout, the settings dialog, the notifications panel, manual tree ordering, serial sessions with a handshake, the embedded WebKit view and the reliability pass. 0.6.4 replaces it. Human acceptance is still pending, so this is a preview release, not an accepted one.
